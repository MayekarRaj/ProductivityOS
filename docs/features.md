# Features — Personal Productivity OS (v2)

Complete feature reference for the app. This is the *what* — for the *how*, see architecture.md and data-model.md.

The entire app is organized around 6 life/work areas. Every task, event, and habit belongs to one.

|---|---|---|---|
| `job` | Lumeglobal | 💼 | Blue |
| `getfly` | Getfly | 🚀 | Purple |
| `mirai` | Mirai | ⚡ | Green |
| `vamoss` | Vamoss | 🔥 | Orange |

## Navigation

Four main tabs, always visible:

- **Today** — default view, always opens to the current day
- **Week** — full 7-day overview
- **Habits** — dedicated habit tracker
- **Stats** — analytics and weekly progress

Smooth animated transitions between tabs.

## 1. Today View

The primary daily workspace. Everything you need for the day in one place.

### 1a. Day Header
- Current day name + full date
- Home base area badge (color-coded, matches area color)
- Home base can be changed inline via dropdown

### 1b. Energy Check-In
- Emoji selector row at the top: 😴 Drained / 😐 Okay / ⚡ Charged / 🔥 Peak
- Selection saved per day, persists in the database
- Used in Stats to correlate energy with productivity patterns

### 1c. Events for Today
- List of timed events for the day (distinct from tasks — events have a specific start time)
- Each event shows: title, time, area badge, reminder indicator
- Add event: title, start time, end time (optional), area, remind offset (default 5 min before)
- Events created via Telegram also appear here in real-time (Supabase Realtime)

### 1d. Task List
- Add tasks via text input (Enter or + button)
- Each task optionally tagged to an area (dropdown — defaults to today's home base)
- Check to complete: strikethrough style, stays visible
- Delete button (hover-reveal)
- "Clear completed" bulk action
- Tasks created via Telegram appear here in real-time
- Source badge shows whether task came from web, Telegram, or AI

### 1e. MVD Checkbox (Minimum Viable Day)
- Single prominent toggle: "Mark MVD done"
- Shows the MVD hint text for today's home base area:
  - Lumeglobal: Ship one thing
  - Getfly: 20 min of thinking / planning
  - Mirai: Review one task or push one commit
  - Vamoss: Review one task or push one commit
  - Fitness: 15 min walk or stretch
  - Personal: Open the project once
- Visual celebration state when marked done

### 1f. Pomodoro Focus Timer
- 25 min work / 5 min break cycle (Pomodoro Technique)
- Circular SVG countdown ring with animated stroke
- Start / Pause / Reset controls
- Session label: "Work Session" / "Break Time"
- Auto-switches from work to break when timer hits 0
- Session count: "3 pomodoros today" — saved to database per day
- Timer state is client-only (resets on refresh) — session count is persisted

### 1g. Brain Dump / Inbox
- Text input: "Quick capture — sort later"
- Saved items appear as a list below the input
- Per item actions: "→ Add as Task" (converts to task for today) / Delete
- Items created via Telegram ("just note this down") also appear here
- Clears when converted to task

### 1h. Daily Note
- Freeform textarea: "How did today go? Any blockers?"
- Autosaves to database with debounce
- Prompted by AI in the morning briefing: "How are you feeling about today?"

### 1i. AI Daily Briefing Card
- Shown at the top of Today view (collapsible)
- Generated by Claude at page load, personalized based on:
  - Today's tasks and events
  - Yesterday's energy and completion rate
  - Habit streaks at risk
  - Upcoming event with earliest remind_at
- Example: "You have 4 tasks today. Energy was low yesterday — consider starting with Getfly's 20-min planning. Workout streak at 3 days, don't miss it."

### 1j. Health Tip Card
- Rotates through curated health/productivity tips
- Personalized based on logged sleep hours (if provided) and habit patterns
- Categories: sleep science, focus, recovery, nutrition basics
- Each tip links to a reference (article or doctor source)
- Example: "You logged 5h sleep last night. REM cycles under 6h reduce working memory by ~30%. Try a 20-min nap between 1–3pm."

## 2. Week View

Overview of the full 7-day week.

### 2a. 7-Day Grid
- 7 cards in a responsive grid
- Each card shows:
  - Day name (Mon–Sun)
  - "TODAY" badge on current day
  - Home base emoji + label
  - Task count: "X / Y done"
  - Event count for the day
  - MVD status: checkmark or empty
  - Energy emoji (if set)
- Clicking a card expands an inline detail panel showing that day's tasks and events
- Only one card expanded at a time

### 2b. Home Base Override
- Each day card has a small dropdown to change the home base area
- Change is saved to the database and reflected across all views

### 2c. Default Schedule
| Day | Default Home Base |
|---|---|
| Mon | Getfly |
| Tue | Mirai |
| Wed | Getfly |
| Thu | Vamoss |
| Fri | Getfly |
| Sat | Personal |
| Sun | Fitness |

### 2d. Sunday Review
- Section at the bottom of the Week view (always visible)
- Three guided reflection prompts:
  1. "What's the most important thing for each area this week?"
  2. "Are any deadlines shifting my default day slots?"
  3. "What's my fitness plan for the week?"
- Free-text textarea for each prompt, autosaves
- AI can pre-fill a draft based on the week's task and habit data
- Prompted via Telegram on Sunday evenings

## 3. Habits

Dedicated habit tracker, separate from one-off tasks.

### 3a. Habit Setup
- Add habit: name, linked area, frequency
- Frequency options:
  - Daily (every day)
  - Weekdays only (Mon–Fri)
  - 3× per week
  - Custom days (multi-select Mon–Sun)
- Delete / archive habit (archived habits hide from view but preserve history)

### 3b. Starter Habits (pre-populated, deletable)
- 💪 Workout — Fitness — Daily
- 📚 Read / Study (AWS prep) — Personal — Daily
- 🧘 Morning routine — Personal — Daily
- 💧 Drink water — Fitness — Daily
- 🌙 Wind down / no screens — Personal — Daily

### 3c. Daily Habit Log
- For today: all habits due shown as checkboxes
- One-tap to mark complete
- Skip day button: marks as skipped (preserves streak, max 1/week per habit)

### 3d. Weekly Heatmap
- Per habit: 7 squares (Mon–Sun)
  - Filled (area color) = completed
  - Empty/outlined = missed (was scheduled that day)
  - Gray = not scheduled
  - Amber = skipped (streak protected)
- Streak count below each habit row
- "Don't Break the Chain" visual motivation

### 3e. Streak Protection
- Each habit allows one skip day per week
- Skipped day does not break the streak
- Shown in a distinct amber color in heatmap
- Max 1 skip per habit per week — enforced in app

## 4. Stats View

Weekly analytics to surface patterns.

### 4a. Summary Cards (4 cards at top)
1. Tasks completed this week: X / total
2. MVD days hit: X / 7
3. Habits completed: X / total scheduled
4. Total pomodoros this week

### 4b. Area Breakdown Bar Chart
- Vertical bar chart (Recharts `BarChart`)
- X-axis: each area
- Y-axis: tasks completed
- Bars colored per area color
- Hover tooltip shows exact count

### 4c. Energy vs Completion Line Chart
- Dual line chart (Recharts `LineChart`)
- X-axis: Mon–Sun
- Line 1: Energy level (😴=1, 😐=2, ⚡=3, 🔥=4)
- Line 2: Task completion % per day
- Shows correlation between energy and output
- Helps identify which days to schedule harder work

### 4d. Habit Consistency Table
- List of all habits with: name | area badge | streak | completion % this week
- Sorted ascending by completion % (lowest first = needs most attention)

### 4e. Sleep Patterns (if sleep logged)
- Simple chart: hours slept per night for the week
- Colored indicator: red (<6h), amber (6–7h), green (7–9h)
- Reference line at 8h optimal

### 4f. Weekly Wins (AI-generated)
- Auto-generated celebratory snippets based on data:
  - "You hit your MVD 5 out of 7 days"
  - "Longest habit streak: Workout at 4 days"
  - "Most productive day: Wednesday (8 tasks done)"
  - "3 high-energy days this week — great week"
- Falls back to encouragement if no wins: "Every streak starts at 1. Keep going."

## 5. Telegram Bot

Two-way integration. Send and receive messages on Telegram to manage the app.

### 5a. Setup
- One-time link: send `/start` to the bot → links your Telegram account to the app
- Bot username to be configured during setup

### 5b. What You Can Do via Telegram

**Create tasks:**
> "Add a task to review the Getfly roadmap today"
> "Remind me to send the Mirai invoice tomorrow"

**Schedule events:**
> "Schedule a meeting with the Vamoss team at 3pm tomorrow"
> "Block 2 hours for deep work on Friday at 10am"

**Brain dump:**
> "Note: think about rebranding the personal site"
> "Idea: integrate calendar sync next sprint"

**Query your day:**
> "What's on my plate today?"
> "Do I have anything at 5pm?"

**Mark things done:**
> "Mark workout as done"
> "I completed the Getfly review task"

**Set reminders:**
> "Remind me to take my meds at 8pm"
> "Alert me 10 minutes before the 3pm meeting"

### 5c. Conversational Flow
- The bot asks follow-up questions for missing information:
  - "Schedule a meeting" → "What time? And which day?"
  - "Add a task" → "Got it. What area should I tag it to?"
- State is preserved across messages (multi-turn conversation)
- Confirmation message after every action: "Done! Added 'Getfly roadmap review' to today."

## 6. Notifications & Automated Messages

All notifications are sent via Telegram. All times are in IST (Asia/Kolkata).

### 6a. Morning Briefing — 8:00am daily
Personalized daily digest. Example:
```
Good morning! Here's your Wednesday:

Home base: Getfly 🚀
MVD: 20 min of thinking / planning

Events today:
  10:00am — Standup call
  3:00pm  — Client demo

Tasks (3 pending):
  • Review Getfly roadmap
  • Send Mirai invoice
  • Weekly report draft

Habits due: Workout, Drink water, Morning routine

Energy check: How are you feeling today?
Reply with 1 (drained), 2 (okay), 3 (charged), or 4 (peak)
```

### 6b. Event Reminder — 5 min before start
```
⏰ Reminder: Client demo in 5 minutes (3:00pm)
```
- Fires exactly at `remind_at` timestamp
- Default: 5 min before event
- Configurable per event

### 6c. Pre-event Alert — at scheduled time
```
🔔 Client demo starting now (3:00pm)
```

### 6d. Habit Reminder — 9:00pm daily
- Only sends if habits are unchecked for the day
```
Evening check-in! You haven't logged today's habits:
  • Workout 💪 (streak: 3 days)
  • Wind down 🌙

Reply "done [habit name]" to mark complete.
```

### 6e. Weekly Review Prompt — Sunday 7:00pm
```
It's Sunday! Time for your weekly review.
Open the app → Week tab → Sunday Review section.

This week: 5/7 MVD days hit, 12 tasks completed.
Your best habit streak: Workout at 4 days.
```

### 6f. Custom Reminders
- Created inline: "Remind me at 6pm to call mom"
- Stored as `notifications` row with `scheduled_at`
- Sent via Trigger.dev cron

## 7. Health & Wellness

### 7a. Sleep Logging
- Manual input: "I slept at 11pm, woke at 6:30am" (via Today view or Telegram)
- Stored as `sleep_start` and `sleep_end` on the `days` table
- Displayed in Stats as a weekly sleep chart

### 7b. Health Tip Cards
Curated, referenced tips shown on Today view. Categories:
- **Sleep science** — REM cycles, sleep debt, optimal windows
- **Focus** — ultradian rhythms, deep work blocks, decision fatigue
- **Recovery** — active rest, movement snacks, screen breaks
- **Nutrition** — energy management, hydration impact on cognition

Each tip includes a source (research paper, doctor reference, or known health publication). Tips rotate daily.

### 7c. Personalized Suggestions
When sleep < 6h is logged, the AI briefing adjusts:
- Suggests lighter tasks first
- Recommends a nap window (1–3pm)
- Flags habit reminders as "recovery day — still worth showing up small"

## 8. PWA (Progressive Web App)

- Installable on iPhone/Android homescreen
- Offline support: Today view works without internet (reads cached data)
- Push notifications via service worker (future scope — for now Telegram handles this)
- Mobile-first responsive layout
- App manifest: dark theme, app icon, splash screen

## UI / UX Standards

- Dark theme throughout — `#0c0c0f` background, `#161620` cards
- DM Mono font for all UI labels, inputs, meta text
- Space Grotesk for headings and display text
- Area colors used consistently: borders, badges, highlights, chart bars
- Every emoji paired with a text label (accessibility)
- Hover states on all interactive elements
- Loading skeletons while data fetches
- Empty states with helpful prompts (not blank screens)
- Error states with actionable messages
- Smooth fade/slide transitions between tabs and expanded panels
- Colored focus rings on inputs matching the active area
